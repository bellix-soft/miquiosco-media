# miquiosco-media

Piezas finales y **ya aprobadas** de las redes de [miquiosco.com](https://miquiosco.com). Este repo es público solo para que Metricool pueda descargar las imágenes y videos al programar las publicaciones.

- Estructura: `AAAA/MM/AAAA-MM-DD-<slug>-<ancho>x<alto>.<jpg|mp4>`
- Los archivos no se reemplazan: si una pieza cambia, se sube con otro nombre (GitHub cachea las URLs raw).
- Aquí no van borradores, textos ni planes. Eso vive en el repo privado de contenido.
